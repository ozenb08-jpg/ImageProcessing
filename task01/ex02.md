## Part 3 – Color Image Shape

The shape of the color image is `(100, 200, 3)`.

- 100 represents the height (rows).
- 200 represents the width (columns).
- 3 represents the RGB color channels.

## Part 5 – Memory Calculation

A color image with `uint8` values uses 3 bytes per pixel.

**1920 × 1080 image:**

1920 × 1080 = 2,073,600 pixels.

2,073,600 × 3 = **6,220,800 bytes**.

**12-megapixel image:**

12,000,000 × 3 = **36,000,000 bytes**.

Both results were verified using `np.zeros(...).nbytes`.

## Part 6 – Understanding Axis

`axis=0` sums the values in each column, across the rows.

Result: `[12, 15, 18, 21]`

`axis=1` sums the values in each row, across the columns.

Result: `[6, 22, 38]`

Without an axis, `sum()` adds all the values in the array.

Result: `66`.
