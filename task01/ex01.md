a = np.array([

## Explanation of My Mistakes

- **`a[1, 2]` and `a[0, 1]`:** I confused the positions in the array. Python starts counting indexes at 0, and the first index is the row while the second is the column.
- **`a.max(axis=0)` and `a.max(axis=1)`:** I confused the axes. `axis=0` finds the maximum in each column, while `axis=1` finds the maximum in each row.
- **`a.size`:** I initially thought that `size` meant the number of columns, but it actually means the total number of elements in the array (2 rows × 3 columns = 6).

## Note on Prediction Timing

The predictions for `a + 10`, `a - 20`, and `a * 2` were recorded after the code had already been run, so they are not independent pre-run predictions.

## What I Learned

- `shape` gives the number of rows and columns; `size` counts elements; `nbytes` counts bytes used by the array data.
- A `uint8` value uses one byte and can represent values from 0 to 255. NumPy array arithmetic can wrap around when results exceed that range.
- NumPy uses zero-based indexing.
